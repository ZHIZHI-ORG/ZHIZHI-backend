# weighted_wuxing_v2_9 五行能量算法说明

> **Status:** CURRENT
> **Release:** SHIPPABLE
> **Verification:** COMMITTED
> **Last verified:** 2026-07-11
> **Sources:** `baziCalculator.ts`、`weightedWuxing.test.ts`、固定案例

## 1. 产品结论

`weighted_wuxing_v2_9` 的目标不是做一个“八个字数数量”的玩具统计，而是给前端八字资料页提供可解释的五行能量强度与占比。

对产品的意义：

- 用户看到的是五行能量结构：哪个元素强、哪个元素弱、强弱差距多大。
- 前端“木火土金水 / 五德”展示可以直接使用 `scores[element].percent`。
- 专业解释页可以使用 `contributions` 展开每个分数来源，解释为什么不是简单按字数平均。
- 日主强弱单独输出在 `dayMasterStrength`，不和五行总能量混成同一个结论。

算法边界：

- 它是原局静态能量评分，不直接等同于喜忌、格局成败、用神判断。
- 它会量化月令、藏干、透干、通根、合冲刑害、生克流通，但不会递归推演无限生克。
- 它追求“命理结构合理 + C 端结果稳定”，不是宣称存在唯一绝对分数。

## 2. 输入与输出

代码位置：

- `api/src/utils/baziCalculator.ts`
- 主入口：`calculateWeightedWuxingFromPillars(...)`
- 当前版本：`methodVersion: weighted_wuxing_v2_9`

输入：

- 四柱：年柱、月柱、日柱、时柱
- 每柱天干、地支、天干五行、地支五行、藏干
- 月令地支
- 日主天干

输出：

```ts
{
  methodVersion: 'weighted_wuxing_v2_9',
  scores: {
    木: { raw: number, percent: number },
    火: { raw: number, percent: number },
    土: { raw: number, percent: number },
    金: { raw: number, percent: number },
    水: { raw: number, percent: number }
  },
  dominant: string,
  weakest: string,
  balanceIndex: number,
  dayMasterStrength: {
    score: number,
    label: string,
    supportScore: number,
    drainScore: number
  },
  majorFactors: string[],
  contributions: WeightedWuxingContribution[]
}
```

最终百分比公式：

```text
某五行百分比 = 某五行 raw / 五行 raw 总和 * 100
```

平衡度公式：

```text
balanceIndex = 1 - sum(abs(各五行百分比 - 20)) / 160
```

`balanceIndex` 越接近 1，五行越平均。

## 3. 总体计算顺序

当前算法按以下顺序累加贡献项：

1. 天干显性能量
2. 地支藏干能量
3. 透干通根 / 同气通根
4. 天干贴身相克
5. 地支合冲刑害、三合、三会、六合
6. 天干五合
7. 五行生克流通
8. 负分归零保护
9. 百分比、强弱、平衡度、日主强弱输出

所有贡献项都会先进入 `rawScores`。最后才做百分比归一化。

## 4. 基础权重

### 4.1 天干位置权重

| 位置 | 权重 | 命理含义 |
| --- | ---: | --- |
| 年干 | 0.6 | 远端背景、祖上环境 |
| 月干 | 1.5 | 月令门户，影响力最强 |
| 日干 | 1.2 | 日主本体，计入五行总能量 |
| 时干 | 1.0 | 后端输出、晚景与行动侧 |

天干分数：

```text
天干分 = 天干位置权重 * 月令季节系数
```

### 4.2 地支位置权重

| 位置 | 权重 | 命理含义 |
| --- | ---: | --- |
| 年支 | 0.6 | 远端根气 |
| 月支 | 3.0 | 月令提纲，原局气势核心 |
| 日支 | 1.5 | 日主坐支、贴身环境 |
| 时支 | 1.0 | 后续输出与结果位 |

地支本身不直接给分，只通过藏干给分。

### 4.3 藏干权重

| 地支 | 藏干权重 |
| --- | --- |
| 子 | 1.0 |
| 卯 | 1.0 |
| 酉 | 1.0 |
| 午 | 0.7 / 0.3 |
| 亥 | 0.7 / 0.3 |
| 戌 | 0.65 / 0.2 / 0.15 |
| 丑、寅、辰、巳、未、申 | 0.6 / 0.25 / 0.15 |

这个设计修正了“纯气地支被低估”的问题。子、卯、酉这类专气地支主气按 1.0 计算，而不是按 0.7 计算。

藏干分数：

```text
藏干分 = 地支位置权重 * 藏干权重 * 月支藏干主场修正 * 月令季节系数
```

其中：

```text
月支藏干主场修正 = 1.08 - min(藏干序号, 2) * 0.04
```

也就是：

- 月支主气：1.08
- 月支中气：1.04
- 月支余气：1.00

防重复规则：

- 非月支藏干会乘月令季节系数。
- 月支藏干不再乘全局季节系数，只乘月支藏干主场修正。
- 这样避免“戌月土已经是月令主气，又再次乘土旺季节系数”导致土被重复放大。

## 5. 月令季节系数

月令季节系数表达“得令、相、休、囚”的季节状态。

| 月支 | 木 | 火 | 土 | 金 | 水 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 寅卯 | 1.22 | 1.10 | 0.80 | 0.90 | 1.00 |
| 辰 | 1.05 | 1.05 | 1.18 | 0.85 | 0.95 |
| 巳午 | 1.00 | 1.22 | 1.10 | 0.80 | 0.90 |
| 未 | 0.90 | 1.05 | 1.18 | 0.95 | 0.85 |
| 申酉 | 0.80 | 0.90 | 1.00 | 1.22 | 1.10 |
| 戌 | 0.85 | 0.95 | 1.18 | 0.95 | 1.00 |
| 亥子 | 1.10 | 0.80 | 0.90 | 1.00 | 1.22 |
| 丑 | 0.95 | 0.85 | 1.18 | 1.00 | 1.05 |

当前选择是中等强度的季节系数，避免月令系数单独压倒藏干、透干、通根。

## 6. 通根与透干

### 6.1 同干通根

同干通根指天干透出，并且地支藏干里出现同一个天干。

公式：

```text
同干通根加分 = 根所在支位置权重 * 同干通根权重 * 月令季节系数
```

同干通根权重：

| 藏干数量 | 主气 | 中气 | 余气 |
| --- | ---: | ---: | ---: |
| 1 个藏干 | 0.22 | - | - |
| 2 个藏干 | 0.18 | 0.10 | - |
| 3 个藏干 | 0.16 | 0.09 | 0.04 |

### 6.2 同气通根

同气通根指天干和藏干不是同一个字，但属于同一五行。

公式：

```text
同气通根加分 = 该藏干基础分 * 距离系数
```

距离系数：

| 天干与根的位置距离 | 系数 |
| --- | ---: |
| 同柱 | 0.85 |
| 相邻一柱 | 0.25 |
| 间隔两柱 | 0.15 |
| 间隔三柱 | 0.10 |

防重复规则：

- 藏干基础分已经在第 2 步计入。
- 通根不是再加一份完整藏干，而是只加“透出 + 有根”的协同分。
- 同干通根和同气通根分开：同干更严格，同气更宽，但同气按藏干基础分和距离衰减。

## 7. 天干相克与天干五合

### 7.1 天干贴身相克

只计算相邻天干。

公式：

```text
被克扣分 = 被克天干基础分 * 克制系数
克者耗气 = 被克扣分 * 0.25
```

克制系数：

- 月干克日干：0.10
- 其他相邻天干相克：0.06

### 7.2 天干五合

五合规则：

| 天干组合 | 目标五行 |
| --- | --- |
| 甲己 | 土 |
| 乙庚 | 金 |
| 丙辛 | 水 |
| 丁壬 | 木 |
| 戊癸 | 火 |

能化条件：

- 目标五行得令，或
- 目标五行为任一地支主气，或
- 目标五行同时有透干与藏干，且没有强势克制目标五行的天干。

能化：

```text
目标五行加分 = 0.25 * 目标五行月令季节系数
参与天干原气扣分 = 参与天干基础分 * 0.40
```

合而未化：

```text
目标五行牵合加分 = 0.08 * 目标五行月令季节系数
参与天干原气扣分 = 参与天干基础分 * 0.08 * 距离系数
```

五合距离系数：

- 相邻：1.00
- 间隔两柱：0.55
- 间隔三柱：0.35

防重复规则：

- 化成目标五行时，会扣参与天干原气。
- 合而未化只做轻微牵绊，不把原天干完全改性。

## 8. 地支关系

### 8.1 六冲

六冲组合：

```text
子午、丑未、寅申、卯酉、辰戌、巳亥
```

公式：

```text
被冲藏干扣分 = 该藏干基础分 * 方向性冲击系数
```

方向性冲击系数：

- 对方五行克当前五行，且对方更强：0.15
- 对方五行克当前五行，但当前更强：0.12
- 当前克对方，且当前更强：0.06
- 当前克对方，但对方更强：0.08
- 土库冲：0.08 / 0.10 / 0.12，按双方强弱差调整
- 无明显生克方向：0.08 / 0.10 / 0.12，按双方强弱差调整

### 8.2 六害与刑

六害：

```text
子未、丑午、寅巳、卯辰、申亥、酉戌
```

刑：

```text
子卯、寅巳、巳申、丑戌、戌未、丑未
```

公式：

```text
六害扣分 = 相关地支藏干基础分 * 0.05
刑扣分 = 相关地支藏干基础分 * 0.04
```

### 8.3 三会、三合、六合

三会：

| 组合 | 五行 | 加分 |
| --- | --- | ---: |
| 寅卯辰 | 木 | 地支位置权重合计 * 0.22 * 季节系数 |
| 巳午未 | 火 | 地支位置权重合计 * 0.22 * 季节系数 |
| 申酉戌 | 金 | 地支位置权重合计 * 0.22 * 季节系数 |
| 亥子丑 | 水 | 地支位置权重合计 * 0.22 * 季节系数 |

三合：

| 组合 | 五行 | 加分 |
| --- | --- | ---: |
| 申子辰 | 水 | 地支位置权重合计 * 0.18 * 季节系数 |
| 亥卯未 | 木 | 地支位置权重合计 * 0.18 * 季节系数 |
| 寅午戌 | 火 | 地支位置权重合计 * 0.18 * 季节系数 |
| 巳酉丑 | 金 | 地支位置权重合计 * 0.18 * 季节系数 |

六合：

| 组合 | 五行 |
| --- | --- |
| 子丑 | 土 |
| 寅亥 | 木 |
| 卯戌 | 火 |
| 辰酉 | 金 |
| 巳申 | 水 |
| 午未 | 土 |

六合加分：

```text
能化 = 两支位置权重合计 * 0.05 * 季节系数
合而未化 = 两支位置权重合计 * 0.015 * 季节系数
```

完整三会、三合、六合能化时，会扣非目标五行藏干原气：

```text
三会成化扣原气 = 非目标藏干基础分 * 0.35
三合成化扣原气 = 非目标藏干基础分 * 0.30
六合成化扣原气 = 非目标藏干基础分 * 0.20
```

半会、半合只计算相邻地支：

```text
相邻半会 = 两支位置权重合计 * 0.04 * 季节系数
相邻半合 = 两支位置权重合计 * 0.05 * 季节系数
```

## 9. 五行生克流通

五行流通使用快照机制。

快照机制的意思是：先复制一份进入流通前的五行分数，再用这份快照计算生克，不让“木生火、火生土、土生金”在同一轮里无限连锁。

### 9.1 相生

条件：

```text
生者分数 >= 五行平均分 * 0.75
```

公式：

```text
被生五行加分 = 生者快照分 * 0.045 * 流通压力
生者泄气扣分 = 生者快照分 * 0.018 * 流通压力
```

流通压力：

- 生者强于被生者：1.0
- 生者不强于被生者：0.6

### 9.2 基础相克约束

每个存在的五行都会形成基础克制关系。

公式：

```text
被克扣分 = min(被克快照分 * 0.012, 克者快照分 * 0.012)
克者耗气 = 被克扣分 * 0.20
```

### 9.3 强势相克压制

条件：

```text
克者分数 >= 五行平均分
克者分数 / 被克分数 >= 1.2
```

公式：

```text
被克扣分 = min(被克快照分 * 0.055, 克者快照分 * 0.03)
克者耗气 = 被克扣分 * 0.30
```

## 10. 日主强弱

五行总分会计入日干本身。

例如庚日主，日干庚金会进入金的总能量，因为它确实是命局中的金。

但日主强弱不重复计算日干本身：

```text
计算日主强弱时跳过 source === 'day_stem'
```

日主强弱计算：

```text
supportScore = 同五行 + 生我五行
drainScore = 其他五行
score = supportScore / (supportScore + drainScore) * 200 - 100
```

标签：

| 分数 | 标签 |
| ---: | --- |
| > 60 | extremely_strong |
| > 30 | strong |
| >= -10 | balanced |
| >= -30 | neutral_weak |
| >= -60 | weak |
| < -60 | extremely_weak |

### 11.7 按五行汇总

下面是 `contributions` 展开的逐项相加。因为最终 raw 使用未四舍五入的内部小数，表内用两位小数相加会有 0.01 左右误差。

#### 木

```text
+0.51 年干乙木显性能量
+0.26 时支亥藏甲木
+0.15 年支亥藏甲木
+0.13 乙木得年亥藏甲同气通根
+0.12 水生木
+0.03 乙木得时亥藏甲同气通根
-0.02 乙庚合牵绊乙木
-0.01 金克木基础约束
= 1.16 raw / 10.63%
```

## 13. 当前算法的重复计算防线

1. 地支不直接给五行本体分，只通过藏干给分。
2. 月支藏干不乘全局季节系数，只做月支主场修正。
3. 通根只加协同分，不重复加完整藏干基础分。
4. 天干五合能化时会扣参与天干原气，合而未化只轻微牵绊。
5. 三会、三合、六合能化时会扣参与地支非目标藏干原气。
6. 生克流通使用快照，避免循环递归放大。
7. 克制关系同时扣被克者和克者自身耗气。
8. 日主强弱排除 `day_stem`，避免日干本体在强弱判断里重复生扶自己。

## 14. 前端使用建议

资料页五行 / 五德展示：

- 使用 `weightedWuxing.scores[element].percent`
- 强弱排序使用 `weightedWuxing.dominant` 和 `weightedWuxing.weakest`
- 展开解释使用 `weightedWuxing.contributions`

解释页建议分层展示：

1. 总占比：木火土金水雷达图或条形图
2. 主要来源：取 `contributions` 里绝对值最大的前 8 到 12 项
3. 专业解释：按“天干、藏干、通根、合冲、生克流通”分组展示
4. 日主强弱：单独展示 `dayMasterStrength`，不要把它等同于五行占比
