# 喜忌用神调候规则索引

> **Status:** ROADMAP
> **Release:** EXPERIMENTAL
> **Verification:** COMMITTED
> **Last verified:** 2026-07-11
> **Sources:** 规则索引与 v1 计划；不是当前完整运行时判断合同

## 1. 文档定位

这份文档定义命理判断层里的喜忌、用神和调候规则索引。

它回答的是：

```text
这个命盘为什么喜某些五行或十神？
为什么忌某些五行或十神？
判断用神时先看什么，后看什么？
调候、扶抑、通关、病药之间如何排序？
```

它不负责：

```text
直接给用户一句绝对吉凶断语
把五行缺失等同于用神
把五行百分比直接等同于喜忌
把神煞命中直接等同于用神
```

产品意义：

- 前端和 AI 可以从稳定的判断链生成解释，而不是从五行分数直接跳到结论。
- 用户看到的喜忌用神有证据来源，可以追溯到四柱、月令、日主强弱、寒暖燥湿、十神结构和干支关系。
- 同一个命盘在资料页、年度运势、每日运势、问答追问中可以保持一致口径。

## 2. 与现有层的边界

| 层 | 已有或拟建 | 负责内容 | 是否直接给喜忌 |
| --- | --- | --- | --- |
| 排盘事实层 | 已有 | 四柱、十神、藏干、纳音、旬空、十二长生 | 否 |
| 神煞事实层 | 已有 | 神煞是否命中 | 否 |
| 干支关系事实层 | 已有 | 合冲刑害、三合、三会、暗合、伏吟等 | 否 |
| 五行能量层 | 已有 | 木火土金水 raw / percent、dominant、weakest | 否 |
| 日主强弱层 | 已有 | `dayMasterStrength` | 否，只提供强弱依据 |
| 喜忌用神调候层 | 本文定义 | 调候、扶抑、通关、病药、喜忌候选 | 是，但输出候选和证据 |

关键边界：

- 五行强不等于一定忌，五行弱不等于一定喜。
- 缺某五行不等于该五行就是用神。
- 调候用神不一定等于扶抑用神。
- 用神是解决命局主要问题的工具，喜神是辅助用神的力量，忌神是加重问题或损伤用神的力量。
- 事实层只说明规则命中，喜忌层才负责判断该事实对命局结构的影响。

## 3. 核心术语

### 3.1 喜神

喜神是对命局有帮助的五行或十神。

常见来源：

- 生扶用神。
- 协助调候。
- 帮助日主达到平衡。
- 帮助格局成立。
- 化解冲突关系。

产品口径：

```text
喜神 = 有助于主问题被缓解的辅助力量
```

### 3.2 忌神

忌神是加重命局问题或损伤用神的五行或十神。

常见来源：

- 加重寒暖燥湿失衡。
- 让日主更偏强或更偏弱。
- 攻击用神。
- 帮助已经过旺的结构继续膨胀。
- 破坏格局或通关路径。

产品口径：

```text
忌神 = 让命局核心问题更严重的力量
```

### 3.3 用神

用神是命局最需要的核心解决工具。

常见类型：

| 类型 | 白话解释 | 例子 |
| --- | --- | --- |
| 调候用神 | 先解决寒暖燥湿问题 | 冬水太寒，先要火暖 |
| 扶抑用神 | 扶弱或抑强 | 日主弱取印比，日主强取食伤财官 |
| 通关用神 | 两股力量冲突时做中间转化 | 金木冲突，用水通关 |
| 病药用神 | 找到命局病点，再找药 | 财旺身弱，以印比为药 |
| 格局用神 | 服务格局成败 | 官格喜印财，伤官格喜财印 |

产品口径：

```text
用神 = 当前判断链里优先级最高的解题工具
```

### 3.4 调候

调候是先看命局气候是否失衡。

它主要判断：

- 寒暖：太寒要火，太热要水。
- 燥湿：太燥要水润，太湿要火土化湿。
- 季节：月令决定环境底色。
- 日主材质：同样的季节，对不同日主影响不同。

产品口径：

```text
调候 = 先判断这个命盘的环境是否太冷、太热、太干、太湿
```

### 3.5 扶抑

扶抑是根据日主强弱判断该扶还是该泄、耗、克。

规则：

- 日主偏弱：优先看印、比劫是否能扶身。
- 日主偏强：优先看食伤、财、官杀是否能泄耗制身。
- 日主接近平衡：不强行扶抑，转看调候、通关和结构病点。

产品口径：

```text
扶抑 = 日主太弱就扶，太强就泄耗克制
```

### 3.6 通关

通关是两股力量直接冲突时，用第三种五行做转化。

五行通关索引：

| 冲突 | 通关五行 | 逻辑 |
| --- | --- | --- |
| 木土冲突 | 火 | 木生火，火生土 |
| 土水冲突 | 金 | 土生金，金生水 |
| 水火冲突 | 木 | 水生木，木生火 |
| 火金冲突 | 土 | 火生土，土生金 |
| 金木冲突 | 水 | 金生水，水生木 |

产品口径：

```text
通关 = 不让两种力量硬碰硬，而是找中间桥梁
```

### 3.7 病药

病药是先找命局主要问题，再找对应解决方式。

例子：

| 病点 | 药 |
| --- | --- |
| 财旺身弱 | 印比 |
| 官杀重身弱 | 印、比劫，或食伤制杀 |
| 食伤过泄 | 印、比劫 |
| 印旺身强 | 财、食伤 |
| 比劫重财弱 | 官杀、食伤、财 |
| 寒湿太重 | 火、燥土 |
| 火炎土燥 | 水、金 |

产品口径：

```text
病药 = 先确定命局哪里失衡，再给对应解法
```

## 5. 总体判断顺序

喜忌用神判断必须按顺序执行。

```text
1. 校验排盘基础事实
2. 取日主和月令
3. 判断季节气候：寒、暖、燥、湿
4. 判断日主强弱
5. 判断五行结构偏枯
6. 判断十神结构病点
7. 判断干支冲突和通关需求
8. 生成调候用神候选
9. 生成扶抑用神候选
10. 生成通关用神候选
11. 生成病药用神候选
12. 合并排序，输出主用神、辅用神、喜神、忌神
13. 输出证据链和置信度
```

优先级规则：

| 优先级 | 判断 | 说明 |
| ---: | --- | --- |
| 1 | 调候 | 寒暖燥湿严重失衡时优先 |
| 2 | 日主强弱 | 无严重调候问题时，以扶抑为主 |
| 3 | 结构病点 | 财官印食伤比劫明显偏枯时介入 |
| 4 | 通关 | 明显五行冲突或干支冲战时介入 |
| 5 | 格局候选 | 只作为候选，不在 v1 做终局盖章 |
| 6 | 神煞 | 只能辅助解释，不参与主用神决策 |

## 8. 调候用神规则索引

### 8.1 寒重

命中条件：

- 月令在亥、子、丑。
- 水、寒湿土明显偏重。
- 火弱或无火。
- 日主或关键十神被寒湿困住。

优先用神：

| 优先级 | 五行 | 作用 |
| ---: | --- | --- |
| 1 | 火 | 暖局、解冻、发用 |
| 2 | 土 | 制水、蓄水、稳定结构 |
| 3 | 木 | 引火、生火，但不能被水漂 |

忌神倾向：

- 水继续加寒。
- 金继续生水。
- 湿土无火时加重凝滞。

### 8.2 热重

命中条件：

- 月令在巳、午、未。
- 火土偏旺。
- 水弱或无水。
- 金被火克，木助火过度。

优先用神：

| 优先级 | 五行 | 作用 |
| ---: | --- | --- |
| 1 | 水 | 降温、润燥 |
| 2 | 金 | 生水、制木、保水源 |
| 3 | 湿土 | 蓄水，但燥土不算有效调候 |

忌神倾向：

- 火继续加热。
- 木继续生火。
- 燥土加重干燥。

### 8.3 燥重

命中条件：

- 月令在巳、午、未、申、酉、戌，且火土金燥象明显。
- 水弱或被冲克。
- 木失润，金太燥，土太干。

优先用神：

| 优先级 | 五行 | 作用 |
| ---: | --- | --- |
| 1 | 水 | 润燥 |
| 2 | 金 | 生水，但金过燥需水洗 |
| 3 | 木 | 疏土、生火要谨慎，需水配合 |

忌神倾向：

- 火加燥。
- 燥土埋金克水。
- 木无水时反成枯木助火。

### 8.4 湿重

命中条件：

- 月令在辰、丑、亥、子，或地支湿土、水局明显。
- 土湿、水重、火弱。
- 结构有泥滞不清之象。

优先用神：

| 优先级 | 五行 | 作用 |
| ---: | --- | --- |
| 1 | 火 | 温燥湿土，化寒湿 |
| 2 | 木 | 疏土，但必须有火配合 |
| 3 | 燥土 | 堤防水势，但过多会壅塞 |

忌神倾向：

- 水加湿。
- 金生水。
- 湿土继续堆叠。

## 9. 日主强弱扶抑索引

### 9.1 日主偏弱

命中条件：

- `dayMasterStrength` 为 `weak`、`extremely_weak` 或明显 `neutral_weak`。
- 同五行和生我五行不足。
- 日主无根、根弱、被冲、被泄耗克重。

用神候选：

| 优先级 | 类型 | 五行关系 | 十神 |
| ---: | --- | --- | --- |
| 1 | 生扶 | 生我 | 正印、偏印 |
| 2 | 帮身 | 同我 | 比肩、劫财 |
| 3 | 通关 | 化解克身力量 | 视冲突而定 |

忌神倾向：

- 财星过旺继续耗身。
- 官杀过旺继续克身。
- 食伤过旺继续泄身。

例外：

- 如果命局寒热燥湿极端，调候优先。
- 如果疑似从弱格，不直接取印比，必须降置信度并标记为格局候选。

### 9.2 日主偏强

命中条件：

- `dayMasterStrength` 为 `strong` 或 `extremely_strong`。
- 同五行、印星、根气明显偏重。
- 日主有强根、多帮扶、得月令。

用神候选：

| 优先级 | 类型 | 五行关系 | 十神 |
| ---: | --- | --- | --- |
| 1 | 泄秀 | 我生 | 食神、伤官 |
| 2 | 耗身 | 我克 | 正财、偏财 |
| 3 | 制身 | 克我 | 正官、七杀 |

忌神倾向：

- 印继续生身。
- 比劫继续帮身。

例外：

- 如果官杀太弱无法制强身，不可高置信度取官杀。
- 如果食伤泄秀同时破官，要看官星是否为结构关键。

### 9.3 日主接近平衡

命中条件：

- `dayMasterStrength` 为 `balanced` 或轻微偏弱偏强。
- 五行结构没有绝对偏枯。

判断方向：

- 优先看调候。
- 再看十神结构病点。
- 再看通关需求。
- 不强行给扶抑结论。

## 11. 五行结构病药索引

## 12. 通关规则索引

通关只在有明显冲突时参与排序。

| 结构冲突 | 典型表现 | 通关候选 | 判断重点 |
| --- | --- | --- | --- |
| 金木冲突 | 金旺克木，木弱受伤 | 水 | 水是否有源，是否被土克 |
| 木土冲突 | 木旺克土，土弱不稳 | 火 | 火是否太旺导致燥 |
| 土水冲突 | 土重克水，或水泛土崩 | 金 | 金能否泄土生水 |
| 水火冲突 | 水火直接相战 | 木 | 木能否同时承水生火 |
| 火金冲突 | 火旺克金，金弱受熔 | 土 | 土能否泄火生金，是否燥重 |

通关失败条件：

- 通关五行完全不出现。
- 通关五行被严重冲克。
- 通关五行出现但无根无源。
- 通关五行本身加重调候病点。

## 13. 用神可用性判断

一个候选五行不能只因“理论需要”就成为高置信度用神。

必须检查：

| 检查项 | 高可用 | 低可用 |
| --- | --- | --- |
| 是否透干 | 天干出现，容易发挥 | 只藏不透 |
| 是否通根 | 地支有同气根 | 无根或根被冲 |
| 是否得月令 | 月令支持 | 月令克泄 |
| 是否被合化 | 合化后仍可用 | 被合走或化忌 |
| 是否被冲克 | 稳定 | 被严重冲克 |
| 是否符合调候 | 同时解决气候问题 | 加重寒热燥湿 |
| 是否有源 | 有生扶来源 | 孤立无援 |

输出口径：

```text
需要某五行 = 命局理论需要
可用某五行 = 命盘里有条件发挥
用神候选 = 理论需要 + 具备一定可用性
```

## 14. 喜神、忌神、仇神、闲神索引

| 名称 | 定义 | 输出条件 |
| --- | --- | --- |
| 用神 | 主解决工具 | 排序最高、证据充分 |
| 喜神 | 辅助用神 | 生扶用神，或协助调候、通关 |
| 忌神 | 加重病点 | 让结构更失衡，或直接损伤用神 |
| 仇神 | 帮助忌神 | 生忌神、助忌神、克用神 |
| 闲神 | 影响较小 | 不明显改善或恶化核心问题 |

v1 产品建议：

- 只对用户展示用神、喜神、忌神。
- 仇神和闲神可留给内部判断或专业展开页。
- 不要在 C 端首屏展示过多术语。

## 15. 合并排序规则

候选用神排序按以下权重综合：

| 因子 | 权重倾向 | 说明 |
| --- | ---: | --- |
| 调候必要性 | 最高 | 寒热燥湿极端时优先 |
| 日主强弱必要性 | 高 | 决定扶抑方向 |
| 病药命中强度 | 高 | 十神结构越偏，权重越高 |
| 通关必要性 | 中高 | 冲突明显时上升 |
| 可用性 | 高 | 无根无源则降级 |
| 与现有五行分一致性 | 中 | 只能辅助，不直接定论 |
| 格局候选 | 中 | v1 不做终断 |
| 神煞 | 低 | 不参与主排序 |

主用神判定：

```text
主用神 = 最能解决当前命局核心问题，且具备一定可用性的五行或十神
```

辅用神判定：

```text
辅用神 = 支持主用神，或解决第二问题的五行或十神
```

喜神判定：

```text
喜神 = 生扶主用神、辅助调候、帮助通关或让结构更平衡的力量
```

忌神判定：

```text
忌神 = 加重核心病点、压制主用神、破坏通关或让结构更偏的力量
```

## 16. 置信度规则

| 置信度 | 条件 |
| --- | --- |
| high | 调候、强弱、十神病点、可用性方向一致 |
| medium | 主方向明确，但存在一到两个冲突条件 |
| low | 疑似特殊格局、从格、化格，或关键输入不足 |

必须降置信度的情况：

- 出生时间未知或跨时辰风险高。
- 出生地经纬度缺失且真太阳时可能跨时辰。
- 日主强弱接近临界值。
- 五行分数与十神结构判断冲突。
- 候选用神完全不透不根。
- 疑似从格、化格、专旺格。
- 大运流年强烈改变短期体感，但原局判断尚未稳定。

## 19. 不纳入 v1 的内容

以下内容可以作为后续版本，不建议在第一轮喜忌用神调候层直接实现：

- 完整格局成败终断。
- 从格、化格、专旺格的高置信度自动判定。
- 古籍断语库。
- 神煞直接参与用神排序。
- 现实行为建议的绝对化承诺。
- 单一吉凶总分。

## 20. v1 成功标准

这层规则完成后，应该能做到：

- 解释为什么不是“缺什么补什么”。
- 区分调候用神和扶抑用神。
- 给出主用神、辅用神、喜神、忌神候选。
- 每个候选都带证据和置信度。
- AI 只能基于这层输出解释，不能自行发明喜忌。
- 当前资料页和未来运势页能复用同一套判断口径。
