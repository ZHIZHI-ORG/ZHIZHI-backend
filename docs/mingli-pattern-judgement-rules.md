# 命理格局判断规则文档

> **Status:** PARTIAL
> **Release:** EXPERIMENTAL
> **Verification:** COMMITTED
> **Last verified:** 2026-07-11
> **Sources:** `patternJudgement.ts`、`zipingStructureFacts.ts`、`patternJudgement.test.ts`

> 基础候选和部分状态合同已有代码，成格、败格、破格、救应仍包含规划内容。每一阶段以文内明确边界和自动测试为准。

## 1. 产品结论

格局判断层不属于基础事实层。它读取事实层证据，然后判断：

```text
这张命盘有哪些格局候选？
哪个候选最可能成为主格？
该格局有没有成格、败格、破格、救应？
是否存在高置信特殊格局需要覆盖普通格局？
```

对产品的意义：

- 事实层保证“命盘里有什么”不被解释层捏造。
- 格局层保证“结构入口是什么”不被五行缺什么、神煞标签、单点十神带偏。
- 喜忌用神层必须读取格局层结果，但不能反过来改写格局事实。

一句话边界：

```text
事实层给证据，格局层定结构，喜忌用神层定解决工具，解释层才输出用户语言。
```

## 2. 范围

本文规划前三个阶段。

| 阶段 | 范围 | 输出 |
| --- | --- | --- |
| 阶段 1 | 基础格局候选、杂气格局候选 | `pattern_candidates` |
| 阶段 2 | 成格、败格、破格、救应 | `pattern_judgement` |
| 阶段 3 | 高置信特殊格局：从格、专旺格、化气格 | `special_pattern_judgement` |

本文不做：

- 喜忌用神终断。
- 富贵贫贱、婚姻、疾病、寿命等断语。
- 罕见外格全集终断，例如飞天禄马、倒冲禄马、井栏叉、子遥巳、壬骑龙背、拱禄、拱贵等。
- 神煞直接参与格局定性。

## 3. 输入依赖

格局层必须读取以下事实。

| 输入 | 来源 | 用途 |
| --- | --- | --- |
| 四柱天干地支 | 排盘事实层 | 定日主、月令、透干、地支 |
| 日主 | 排盘事实层 | 计算十神 |
| 月支 / 月令 | 排盘事实层 | 主格局入口 |
| 地支藏干 | 藏干事实层 | 判断月令藏干、根气、杂气 |
| 天干十神 | 十神事实层 | 判断透干 |
| 藏干十神 | 十神事实层 | 判断月令司令十神、杂气十神 |
| 合冲刑害破 | 干支关系事实层 | 判断破格、救应、冲开、合去 |
| 三合三会半合拱合 | 干支关系事实层 | 判断引动和特殊格成势 |
| 日主旺衰 | 旺衰事实层 | 判断身强、身弱、从格、承载 |
| 五行加权结构 | 五行能量层 | 辅助判断成势，不直接定格 |
| 调候事实 | 调候索引层 | 只作格局解释约束，不替代格局 |

## 4. 总执行顺序

```text
1. 读取月令和日主。
2. 计算月令司令十神。
3. 生成基础格局候选。
4. 如果月支为辰戌丑未，生成杂气格局候选。
5. 对每个候选执行成格、败格、救应规则。
6. 生成普通主格局排序。
7. 执行从格、专旺格、化气格检查。
8. 如果特殊格局高置信成立，覆盖或降级普通主格局。
9. 输出主格局、辅助格局、候选格局、破格项、救应项和置信度。
```

## 5. 输出契约

```yaml
pattern_judgement:
  primary_pattern:
    id: zheng_guan_ge
    name: 正官格
    family: regular
    status: confirmed
    confidence: high
    entry: month_command
    evidence: []
    success_hits: []
    failure_hits: []
    rescue_hits: []
    unresolved_conflicts: []
  secondary_patterns: []
  mixed_qi_patterns: []
  special_patterns: []
  rejected_patterns: []
  notes: []
```

### 5.1 status 口径

| 状态 | 含义 |
| --- | --- |
| `candidate` | 有格局入口，但证据不足 |
| `probable` | 证据较完整，但成败救应仍有冲突 |
| `confirmed` | 候选、成格条件清楚，破格项可控 |
| `rescued` | 有破格项，但救应成立 |
| `mixed` | 多格并见，暂不强行单一化 |
| `broken` | 主结构被破坏，救应不足 |
| `rejected` | 候选条件不成立或被强冲突排除 |

### 5.2 confidence 口径

| 置信度 | 条件 |
| --- | --- |
| `high` | 月令入口明确，关键格神透出或有力，成败救应方向一致 |
| `medium` | 月令入口明确，但格神不透或破救并见 |
| `low` | 只藏不透、只被引动、或关键证据不足 |

## 6. 阶段 1：基础格局候选

### 6.1 基本原则

基础格局以月令为主。

规则：

```text
月令有可用十神，先以月令十神取格。
月令为比劫，进入建禄、月劫、阳刃体系，再另取财官杀食伤为用。
非月令透干不能直接越过月令成为主格，只能成为辅助候选。
神煞不参与基础格局取格。
```

### 6.2 透干定义

透干就是某个藏干对应的天干出现在年干、月干、时干。

规则：

```text
日干是日主，不作为格神透干证据。
月干透出权重最高。
年干透出代表外部、早年、来源。
时干透出代表后续、子息、结果。
同一格神多处透出，增强候选强度，但也要检查混杂。
```

### 6.3 通根定义

通根就是某个格神对应的天干在地支藏干中出现。

强度顺序：

```text
月支藏干 > 日支藏干 > 时支藏干 > 年支藏干
主气根 > 中气根 > 余气根
```

规则：

```text
格神无根，只透天干，候选可成立但置信度下降。
格神有月令根，候选强度上升。
格神根被冲合刑害影响，进入成败层判断，不在候选层直接排除。
```

### 6.4 基础格局候选表

| 月令司令十神 | 候选格局 | 说明 |
| --- | --- | --- |
| 正官 | 正官格 | 以官星为主结构 |
| 七杀 | 七杀格 / 偏官格 | 以杀星为主结构，后续必须看制化 |
| 正财 | 正财格 | 以财星为主结构 |
| 偏财 | 偏财格 | 以偏财为主结构 |
| 正印 | 正印格 | 以印星为主结构 |
| 偏印 | 偏印格 / 枭印格 | 以偏印为主结构，后续检查夺食 |
| 食神 | 食神格 | 以食神为主结构 |
| 伤官 | 伤官格 | 以伤官为主结构，后续检查见官、配印、生财 |
| 比肩 | 建禄格候选 | 月令同我，需另取财官杀食伤 |
| 劫财 | 月劫格候选 / 阳刃格候选 | 阳干帝旺月另判阳刃 |

### 6.5 正官格候选规则

命中条件：

```text
月令司令十神为正官。
或月支主气十神为正官，且 v1 未启用节气分日司令。
```

增强条件：

```text
正官透于月干。
正官在月支主气有根。
财星透出或藏根，可以生官。
印星透出或藏根，可以护官。
官星不混七杀，或有合杀留官证据。
```

降级条件：

```text
伤官透出。
官星被合去。
月令官星被冲。
官杀混杂无清。
```

候选输出：

```yaml
id: zheng_guan_ge_candidate
entry: month_command
evidence:
  - 月令司令十神为正官
  - 正官透干 / 不透干
  - 正官有根 / 无根
```

### 6.6 七杀格候选规则

命中条件：

```text
月令司令十神为七杀。
或月支主气十神为七杀，且 v1 未启用节气分日司令。
```

增强条件：

```text
七杀透干。
七杀有月令根。
食神透出，可制杀。
印星透出，可化杀。
阳刃或比劫有力，可承杀。
```

降级条件：

```text
财星透出直接生杀而无制化。
正官并见，官杀混杂。
食神被偏印克制。
日主极弱且无印比承载。
```

候选输出：

```yaml
id: qi_sha_ge_candidate
entry: month_command
evidence:
  - 月令司令十神为七杀
  - 七杀透干 / 不透干
  - 制杀、化杀、承杀证据
```

### 6.7 财格候选规则

正财格命中条件：

```text
月令司令十神为正财。
```

偏财格命中条件：

```text
月令司令十神为偏财。
```

增强条件：

```text
财星透干。
财星有月令根。
食伤透出，可生财。
官星透出，可形成财生官。
日主有根或有印比承载财。
```

降级条件：

```text
比劫重重争财。
财星透杀而无制。
财星被合去。
日主弱而财重，无印比承载。
```

### 6.8 印格候选规则

正印格命中条件：

```text
月令司令十神为正印。
```

偏印格命中条件：

```text
月令司令十神为偏印。
```

增强条件：

```text
印星透干。
印星有月令根。
官杀透出，可生印。
日主弱，印星有扶身意义。
身印两旺，有食伤泄秀证据。
```

降级条件：

```text
财星重而破印。
偏印夺食。
印多身强而无泄。
印星被合去或冲损。
```

### 6.9 食神格候选规则

命中条件：

```text
月令司令十神为食神。
```

增强条件：

```text
食神透干。
食神有根。
财星透出，可食神生财。
七杀出现，且食神可制杀。
日主有承载，食神可泄秀。
```

降级条件：

```text
偏印透出夺食。
食神被合去。
食伤混杂过重。
食神生财又透杀，导致财党杀。
```

### 6.10 伤官格候选规则

命中条件：

```text
月令司令十神为伤官。
```

增强条件：

```text
伤官透干。
伤官有根。
财星透出，可伤官生财。
印星透出且有根，可伤官配印。
七杀出现且无财党杀，可伤官驾杀。
```

降级条件：

```text
非金水伤官见官。
伤官生财又带杀。
伤官配印但印弱或被财破。
伤官太轻而身旺印重。
```

### 6.11 建禄格候选规则

命中条件：

```text
月支为日主临官位。
或月令主气十神为比肩。
```

临官对应：

| 日主 | 建禄月支 |
| --- | --- |
| 甲 | 寅 |
| 乙 | 卯 |
| 丙 | 巳 |
| 丁 | 午 |
| 戊 | 巳 |
| 己 | 午 |
| 庚 | 申 |
| 辛 | 酉 |
| 壬 | 亥 |
| 癸 | 子 |

建禄不是直接以比肩为用。规则：

```text
建禄月劫，月令同我，本身不可直接当作普通用神。
必须另看财、官、杀、食、伤是否透干或会支。
候选输出为建禄格候选，同时输出可用之神候选。
```

增强条件：

```text
官星透出并有财印相随。
财星透出并有食伤生财。
七杀透出并有制伏。
食伤透出泄秀。
```

降级条件：

```text
比劫太重，无财官食伤。
财星被比劫争夺且无食伤化劫。
官杀混杂无制。
```

### 6.12 月劫格和阳刃格候选规则

月劫命中条件：

```text
月令主气十神为劫财。
```

阳刃命中条件：

```text
日主为阳干。
月支为日主帝旺 / 羊刃位。
```

阳刃对应：

| 日主 | 阳刃月支 |
| --- | --- |
| 甲 | 卯 |
| 丙 | 午 |
| 戊 | 午 |
| 庚 | 酉 |
| 壬 | 子 |

规则：

```text
阴干不立阳刃格，只按月劫或比劫结构处理。
阳刃格必须进入成败层检查官杀制刃。
阳刃无官杀制伏，不可直接判成格。
```

## 7. 阶段 1：杂气格局候选

### 7.1 杂气触发条件

月支为四墓库时，进入杂气格局候选。

```text
辰、戌、丑、未 = 杂气月
```

四墓库藏干：

| 月支 | 主气 | 中气 | 余气 |
| --- | --- | --- | --- |
| 辰 | 戊 | 乙 | 癸 |
| 戌 | 戊 | 辛 | 丁 |
| 丑 | 己 | 癸 | 辛 |
| 未 | 己 | 丁 | 乙 |

### 7.2 杂气候选生成规则

规则：

```text
将月支全部藏干转为相对日主的十神。
每个非比劫藏干都可以生成一个杂气格局候选。
藏干透干者优先。
藏干不透但被三合三会引动者，作为中置信候选。
只藏于月令且无透出、无引动者，作为低置信候选。
```

不生成的候选：

```text
杂气比肩格。
杂气劫财格。
```

说明：

```text
月令藏干为比劫，只说明日主得根或比劫结构增强，不作为杂气主格。
```

### 7.3 杂气候选强度

| 强度 | 条件 |
| --- | --- |
| 高 | 月令藏干透于月干、年干或时干 |
| 中高 | 月令藏干不透，但三合三会成局引动该五行 |
| 中 | 月令藏干为主气，且同类在其他地支有根 |
| 中低 | 月令藏干为中气或余气，其他地支有根 |
| 低 | 只藏于月令，无透出、无引动 |

### 7.4 多个杂气候选并见

规则：

```text
多个藏干同时透出，不强行删除候选。
先按透干位置、藏干深度、成格条件、破格程度排序。
如果两个候选都具备成格条件，输出主格和辅格。
如果多个候选互相冲突，输出 mixed，不强行终断。
```

排序优先级：

```text
月干透出 > 时干透出 > 年干透出
主气 > 中气 > 余气
成格条件命中 > 只有候选条件
有救应 > 无救应
破格少 > 破格多
```

### 7.5 杂气正官格

候选条件：

```text
月支为辰戌丑未。
月令藏干中存在正官。
正官藏干透出，或被会合引动，或为月令主气。
```

增强条件：

```text
正官透于月干。
财星可生官。
印星可护官。
官星不混七杀，或混而有清。
```

降级条件：

```text
伤官透出克官。
官星被合去。
月令官星受冲且无会合解冲。
官杀混杂无清。
```

### 7.6 杂气七杀格

候选条件：

```text
月支为辰戌丑未。
月令藏干中存在七杀。
七杀藏干透出，或被会合引动，或为月令主气。
```

增强条件：

```text
七杀透干。
食神可制杀。
印星可化杀。
日主有根或有比劫阳刃承杀。
```

降级条件：

```text
财星生杀而无制。
官杀混杂。
七杀重而日主弱，无印比。
食神被枭印夺。
```

杂气七杀格不能只因“七杀藏在辰戌丑未里”直接成立。

### 7.7 杂气正财格

候选条件：

```text
月支为辰戌丑未。
月令藏干中存在正财。
正财藏干透出，或被会合引动，或为月令主气。
```

增强条件：

```text
正财透干，尤其透于月干。
食伤生正财。
正财生官。
日主有承载。
正财与正官、正印位置不相碍。
正财清纯，不与偏财混杂过重。
```

降级条件：

```text
比劫重重争财。
正财透七杀无制。
正财被合去。
身弱财重无印比。
正偏财混杂而无取清。
```

规则说明：

```text
杂气正财格偏向稳定财星结构。
它和杂气偏财格都属于财格体系，但正财更重清纯、稳定、生官和位置妥贴。
不能只输出“杂气财格”，否则后续喜忌和成败救应会丢失正偏差异。
```

### 7.8 杂气偏财格

候选条件：

```text
月支为辰戌丑未。
月令藏干中存在偏财。
偏财藏干透出，或被会合引动，或为月令主气。
```

增强条件：

```text
偏财透干，尤其透于月干或时干。
食伤生偏财。
偏财生杀时，杀必须有制化。
日主有根或印比承载偏财。
偏财不被比劫重夺。
```

降级条件：

```text
比劫重重夺偏财。
偏财党杀而无食神制杀或印化杀。
偏财被合去。
身弱偏财重，无印比承载。
正偏财混杂而无取清。
```

规则说明：

```text
杂气偏财格不能简单按正财格处理。
偏财更容易引动七杀、外部资源和流动性，成败层必须检查“财党杀”和比劫夺财。
```

### 7.9 杂气正印格

候选条件：

```text
月支为辰戌丑未。
月令藏干中存在正印。
正印藏干透出，或被会合引动，或为月令主气。
```

增强条件：

```text
官杀生印。
正印透干，尤其透于月干。
日主弱而正印有扶身作用。
身印两旺且食伤可泄秀。
正印不被财星直接破坏。
```

降级条件：

```text
财重破印。
正印被合去或冲损。
印多身强无泄。
财印相战无通关。
正偏印混杂而偏印夺食。
```

规则说明：

```text
杂气正印格偏向正印扶身、护官、化杀。
它和杂气偏印格不能合并，因为偏印会产生“枭神夺食”等独立破格问题。
```

### 7.10 杂气偏印格

候选条件：

```text
月支为辰戌丑未。
月令藏干中存在偏印。
偏印藏干透出，或被会合引动，或为月令主气。
```

增强条件：

```text
偏印透干，尤其透于月干。
七杀生偏印，形成杀印相生候选。
日主弱而偏印可扶身。
偏印有偏财制化，避免枭神过偏。
偏印与食神不直接相战。
```

降级条件：

```text
偏印夺食。
偏印多而无财制。
日主强而偏印重，无食伤泄秀。
偏印被正财、偏财重破。
偏印与食神同柱或近贴相克。
```

规则说明：

```text
杂气偏印格必须单列。
偏印虽然也属印格体系，但它和食神、偏财、七杀的关系明显不同，不能用正印格规则直接替代。
```

### 7.11 杂气食神格

候选条件：

```text
月支为辰戌丑未。
月令藏干中存在食神。
食神藏干透出，或被会合引动，或为月令主气。
```

```text
食神透干。
食神有根。

七杀出现，且食神可制杀。
日主有根，食神可泄秀。
```

降级条件：

```text
偏印透出夺食。
食神被合去。
食伤混杂过重。
食神生财又见七杀，财党杀而无制。
```

杂气食神格的关键不是“有食神”，而是“食神从月令杂气中透出或被引动”。

### 7.12 杂气伤官格

```text
伤官生财。
伤官配印。
伤官带杀且无财党杀。
```

## 8. 阶段 2：成格、败格、破格、救应

### 8.0 当前规划边界

当前阶段只规划成格方案规则，也就是先实现 `success_rules`。

暂不规划：

```text
failure_rules    败格 / 破格条件
rescue_rules     救应条件
特殊格覆盖普通格
格局终局排序
```

原因：

```text
成格是判断“这个候选是否有资格成为主结构”。
败格、破格、救应是判断“已经有主结构后，它有没有被破坏、能不能被救”。
如果过早把破格和救应塞进成格层，产品会把入口判断和终局判断混在一起。
```

当前阶段输出建议：

```yaml
pattern_success_judgement:
  primary_candidate_id: zheng_guan_ge_candidate
  status: success_candidate
  confidence: high
  success_hits: []
  notes:
    - 只判断成格条件，不输出破格或救应终断。
```

### 8.1 总原则

候选不等于成格。

完整格局判断最终会拆成四类规则：

```text
candidate_rules  候选条件
success_rules    成格条件
failure_rules    败格 / 破格条件
rescue_rules     救应条件
```

当前只落 `success_rules`。

成格判断看四件事：

| 维度 | 含义 |
| --- | --- |
| 有情 | 格神和配神形成合理生克流通 |
| 有力 | 格神透干、有根、得令、未被严重损伤 |
| 清纯 | 不混杂、不争合、不被乱局污染 |
| 正向配合明确 | 透干、通根、会支、相神能支持主格成立 |

当前阶段不因为破格项直接降级，也不因为救应项直接升格。
破格和救应只在后续 `failure_rules`、`rescue_rules` 实现。

### 8.1.1 会支进入成格的边界

会支就是三合、三会形成完整局势。它可以作为成格证据，但只在正向条件下进入 `success_hits`。

可进入成格的三类情况：

| 场景 | 可以进入成格的原因 | 输出口径 |
| --- | --- | --- |
| 会支引动月令格神 | 会局五行与月令格神同五行，且包含月支 | 格神有力 |
| 会支引动杂气藏干 | 辰戌丑未月中对应藏干不透，但三合三会引动同五行 | 杂气格神被引动 |
| 建禄月劫另取用神 | 会局五行对日主形成财、官杀、食伤 | 另取之神有力 |

暂不进入成格的情况：

```text
会支形成忌神。
会支不包含月支，只在年日时成局。
会支与已透月令主格相冲突。
会支只是破格或救应证据。
```

说明：

```text
这些情况不是不重要，而是不属于“成格方案规则”。
它们后续进入 failure_rules 或 rescue_rules。
```

### 8.2 破格和救应的处理（后续阶段）

本节保留为后续阶段参考，当前成格方案不实现以下规则。

规则：

```text
破格项命中，不立即 rejected。
如果救应项同时命中，状态可为 rescued。
如果破格项多且无救应，状态为 broken。
如果破格项和救应项都弱，状态为 probable 或 mixed。
```

输出口径：

```text
成中有败：主格可成立，但带明显问题。
败中有成：主格原本受损，但救应有效。
破格无救：候选保留，主格降级或拒绝。
```

```text
财星透干或会支成财局，可生官。

官星清纯，不混七杀。
```

```text
伤官克官。

官杀混杂无清。

正官过多而浊。
```

```text
七杀一位清纯，有制有化。
```

```text
官杀混杂无清。
七杀多透，制化不足。
七杀入局但日主无根，且不符合从杀条件。
```

```text
食神制杀。
印星化杀。
合杀留官。
去财存食，使食神能制杀。
比劫或阳刃助身承杀。
```

```text
财逢劫，透官杀以制比劫护财。
财透杀，食神制杀以存财。

财印相见，中隔官星或比劫，使两不相碍。
```

## 9. 阶段 3：高置信特殊格局

### 9.1 特殊格局总原则

特殊格局不能随便覆盖普通格局。

覆盖条件：

```text
普通月令格局不存在、很弱或已破。
特殊格局必备条件全部命中。
破格因素少，且没有强力逆势因素。
特殊格局与月令、全局气势一致。
```

不覆盖条件：

```text
普通月令格局已经 confirmed。
特殊格局只有一两个表面条件。
日主有强根但却判从。
化神不得令但强行判化。
专旺格中出现强财官杀破局。
```

### 9.2 从格总规则

从格就是日主极弱，无法自立，只能顺从全局主势。

从格通用候选条件：

```text
日主不得月令。
日主无强根。
天干无有效印比帮身。
地支无有效印比根。
克、泄、耗日主的一方或多方成势。
全局没有明显逆势力量破从。
```

从格通用拒绝条件：

```text
日主得月令。
日主坐强根。
月支藏日主同类或印星强根。
天干透印比且有根。
地支成印比局。
存在足以扶起日主的运势只可作岁运触发，不改原局从格候选。
```

从格状态：

| 状态 | 含义 |
| --- | --- |
| `follow_candidate` | 日主弱，存在从势可能 |
| `follow_probable` | 日主无根无印比，外势明显 |
| `follow_confirmed` | 从势纯粹，无破从证据 |
| `follow_rejected` | 日主有根、有印比或逆势明显 |

### 9.3 从财格

候选条件：

```text
日主极弱。
财星成势。
食伤能生财。
官杀可顺财势，但不能反成杀重攻身无序。
无印比破从。
```

增强条件：

```text
月令为财星。
财星透干多见。
地支成财局或财星根重。
食伤透出顺生财。
```

破格条件：

```text
印星透出且有根。
比劫透出且有根。
日主坐强根。
财星被严重冲散。
官杀过重，财势转为杀势且无顺从逻辑。
```

输出口径：

```text
只在日主确实无依、财势纯粹时判从财。
如果只是财旺身弱，不能判从财。
```

### 9.4 从杀格

候选条件：

```text
日主极弱。
官杀成势。
财星生官杀。
无印比扶身。
无食伤强力制杀。
```

增强条件：

```text
月令为官杀。
官杀透干。
地支有官杀根或官杀局。
财星顺生官杀。
```

破格条件：

```text
食神或伤官强力制杀。
印星化杀生身且有效。
比劫有根助身。
日主得根。
官杀混杂导致结构不清，且无法取清。
```

输出口径：

```text
杀旺身弱不等于从杀。
只有日主无依且杀势纯粹，才可从杀。
```

### 9.5 从儿格

从儿格就是日主极弱，食伤成势，顺泄为用。

候选条件：

```text
日主极弱。
食伤成势。
食伤透干或地支成食伤局。
财星可顺接食伤之气。
无印星克制食伤。
无比劫强扶日主。
```

增强条件：

```text
月令为食伤。
食伤多透。
食伤有根。
财星透出承接食伤。
```

破格条件：

```text
印星透出克食伤。
日主有强根。
比劫透出有根。
官杀强出，食伤转为制杀而非从儿。
```

输出口径：

```text
食伤旺不等于从儿。
必须日主无依，且食伤成为全局主势。
```

### 9.6 从势格

从势格用于财、官杀、食伤多方合势，但没有单一从财、从杀、从儿那么纯。

候选条件：

```text
日主极弱。
印比无力。
财、官杀、食伤共同成势。
局势整体顺泄、顺克、顺耗日主。
没有单一力量足以独立命名从财、从杀或从儿。
```

降级条件：

```text
任一印比强根出现。
多方力量互相冲突，不能形成顺势。
月令不支持外势。
```

输出口径：

```text
从势格默认最高只到 probable。
除非证据极纯，否则不输出 confirmed。
```

### 9.7 专旺格总规则

专旺格就是日主一方极旺，顺其旺势，不按普通扶抑处理。

通用候选条件：

```text
日主得月令或得强根。
印比同党成势。
地支成方局、三会、三合，支持日主五行。
财官杀力量弱，不能破旺势。
食伤可以顺泄，但不能严重泄破专旺。
```

通用拒绝条件：

```text
官杀强透并有根，直接克制日主。
财星强透，日主旺势转为财战。
月令不支持日主五行。
印比不成势，只是普通身旺。
冲合破坏专旺局。
```

### 9.13 化气格总规则

化气格就是日干参与天干五合，并且合化之气得到月令和地支支持。

天干五合：

| 天干合 | 化神 |
| --- | --- |
| 甲己合 | 土 |
| 乙庚合 | 金 |
| 丙辛合 | 水 |
| 丁壬合 | 木 |
| 戊癸合 | 火 |

候选条件：

```text
日干参与天干五合。
合干出现在月干或时干，年干次之。
化神得月令支持。
地支有化神根，或三合三会支持化神。
原日主本气不强，不抗化。
无争合、妒合。
无强力克制化神的五行。
```

拒绝条件：

```text
日主有强根，不愿化。
化神不得月令。
化神无根。
出现争合或妒合。
克化神之五行强透有根。
合干被冲克严重。
```

输出口径：

```text
合不等于化。
只有月令、地支、透干同时支持化神，才可从化气候选升为 confirmed。
```

## 10. 主格局选择规则

### 10.1 普通主格排序

排序顺序：

```text
1. 月令司令格局 confirmed。
2. 月令主气格局 confirmed。
3. 杂气透干格局 confirmed。
4. 月令司令格局 rescued。
5. 杂气格局 rescued。
6. 月令候选 probable。
7. 非月令辅助候选。
```

### 10.2 特殊格覆盖规则

特殊格可以覆盖普通格，但必须满足：

```text
特殊格 status = confirmed。
普通格 status 不为 confirmed，或普通格已 broken。
特殊格证据纯度高。
特殊格破格项少于普通格破格项。
```

如果普通格和特殊格都强：

```text
输出 mixed。
不强行覆盖。
解释层必须说明“普通月令结构与特殊格局条件并见”。
```

### 10.3 多格并见规则

规则：

```text
主格只选一个。
辅格可以多个。
候选格可以多个。
不允许把所有命中的十神都说成格局。
```

输出口径：

```text
主格 = 最能代表月令和全局结构的格局。
辅格 = 对主格有支持或冲突影响的结构。
候选格 = 证据不足但值得保留的结构。
```

## 11. 与喜忌用神层的关系

格局层输出后，喜忌用神层才能继续判断。

示例：

```text
正官格 confirmed：
  喜忌层优先检查财印是否可用、伤官是否为病、是否需要印护官。

七杀格 rescued：
  喜忌层优先检查食神制杀或印化杀是否是主工具。

财格 broken：
  喜忌层不能直接以财为喜，必须读取破格原因。

从财格 confirmed：
  喜忌层不能按普通身弱取印比，必须顺从财势。
```

## 12. 验证样例要求

每条规则上线前至少需要以下样例：

| 样例类型 | 要求 |
| --- | --- |
| 正向样例 | 候选、成格、救应可以命中 |
| 反向样例 | 同名格局不应误命中 |
| 破格样例 | 候选成立但破格 |
| 救应样例 | 破格后被救 |
| 杂气样例 | 辰戌丑未藏干透出与不透出对比 |
| 特殊格样例 | 从格、专旺、化气各自 confirmed 和 rejected |

验证输出必须包含：

```text
命中规则 ID
证据字段
拒绝原因
置信度
是否影响主格
```

## 13. 推荐实施顺序

### 13.1 第一批

```text
正官格、七杀格、财格、印格、食神格、伤官格。
```

原因：

```text
覆盖大多数命盘。
与《子平真诠》成败救应文本最清楚。
和现有十神、月令、旺衰事实层最容易衔接。
```

### 13.2 第二批

```text
建禄格、月劫格、阳刃格、杂气格局。
```

原因：

```text
需要更多“另取财官杀食伤”的判断。
杂气需要藏干透出和墓库冲合证据。
误判成本比普通格局更高。
```

### 13.3 第三批

```text
从财、从杀、从儿、从势、曲直、炎上、稼穑、从革、润下、五类化气格。
```

原因：

```text
必须依赖旺衰、根气、全局成势、合化支持。
一旦误判，会直接改变喜忌方向。
```
