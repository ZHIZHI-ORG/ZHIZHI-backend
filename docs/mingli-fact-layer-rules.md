# 命理事实层规则说明

> **Status:** PARTIAL
> **Release:** EXPERIMENTAL
> **Verification:** WORKTREE
> **Last verified:** 2026-07-11
> **Sources:** `baziCalculator.ts`、`mingliInteractionEngine.ts`、`zipingStructureFacts.ts`、相关测试

> 本文混合当前规则与后续展示/触发规划。具体字段是否已实现需逐项对照来源；当前工作树正在调整 AI brief 的干支作用输入。

## 1. 核心定位

命理事实层回答的是：

```text
这个命盘里客观出现了哪些命理事实？
```

它不负责直接回答：

```text
这个五行最终占多少分？
这个神煞一定吉还是一定凶？
这个关系一定带来什么结果？
```

对产品的意义：

- 前端资料页可以稳定展示四柱、十神、藏干、神煞、合冲刑害等事实。
- AI 只能基于事实层做解释，不能捏造不存在的关系。
- 五行评分层可以引用事实层，但事实层本身不等于五行评分。

## 2. 事实层与评分层边界

| 层 | 负责内容 | 是否打五行分 | 产品用途 |
| --- | --- | --- | --- |
| 排盘事实层 | 四柱、十神、藏干、纳音、旬空、十二长生 | 否 | 命盘资料页 |
| 神煞事实层 | 天乙、文昌、桃花、学堂、天罗地网等 | 否 | 标签和解释证据 |
| 干支关系事实层 | 合、冲、刑、害、破、三合、三会、半合、拱合、拱会、暗合、暗会、伏吟 | 否，但有关系强度 | 关系面板和运势触发 |
| 五行能量层 | 木火土金水 raw / percent | 是 | 五德/五行强度展示 |

关键边界：

- `事实命中` 只说明规则成立。
- `关系强度` 只用于排序，不代表吉凶。
- `五行百分比` 才是能量评分。
- 事实层已经能识别的关系，不代表五行评分层一定已经把它折算进 raw 分。

例子：

```text
申辰拱合子水 = 命理事实层可以命中
是否给水加分 = 五行能量算法单独决定
```

## 3. 排盘基础事实

### 3.1 四柱

四柱包含：

| 柱 | 代表 |
| --- | --- |
| 年柱 | 早年、祖上、外部背景 |
| 月柱 | 月令、社会角色、父母、事业环境 |
| 日柱 | 日主、自身、伴侣宫 |
| 时柱 | 子女、输出、晚景、未来走向 |

每柱输出：

- 天干
- 地支
- 干支组合
- 天干五行
- 地支五行
- 天干十神
- 地支藏干
- 藏干十神
- 十二长生
- 自坐十二长生
- 纳音
- 旬空
- 神煞

### 3.2 日主

日主就是日柱天干。

所有十神、十二长生、大运流年关系，都以日主作为核心参照。

例子：

```text
庚子日：日主 = 庚金
丙戌日：日主 = 丙火
```

### 3.3 真太阳时

如果用户提供出生地经纬度，后端会先把钟表时间校正为真太阳时，再排盘。

规则事实：

- 经度会影响当地太阳时间。
- 均时差会修正太阳视运动误差。
- 纬度当前作为地点事实保存，不参与分钟修正。
- 如果校正后跨时辰，时柱会变化。
- 如果校正后跨日期，日柱也可能变化。

产品口径：

```text
有经纬度：按真太阳时排盘
无经纬度：按标准钟表时间排盘
```

### 3.4 农历与公历

规则：

- 公历输入直接排盘。
- 农历输入先转公历，再排盘。
- 出生时辰仍使用用户传入的小时和分钟。

### 3.5 性别

性别不改变原局四柱。

性别影响：

- 大运顺逆
- 起运时间
- 天罗地网等部分性别相关神煞

性别不影响：

- 原局天干地支
- 原局五行事实
- 原局合冲刑害事实

## 4. 十神规则

十神以日主为中心判断。

| 关系 | 同阴阳 | 异阴阳 |
| --- | --- | --- |
| 同我五行 | 比肩 | 劫财 |
| 我生之五行 | 食神 | 伤官 |
| 生我之五行 | 偏印 | 正印 |
| 我克之五行 | 偏财 | 正财 |
| 克我之五行 | 七杀 | 正官 |

简写口径：

| 全称 | 简称 |
| --- | --- |
| 正印 | 印 |
| 正官 | 官 |
| 劫财 | 劫 |
| 伤官 | 伤 |
| 正财 | 财 |
| 七杀 | 杀 |
| 偏印 | 枭 |
| 比肩 | 比 |
| 食神 | 食 |
| 偏财 | 才 |

产品口径：

- 原局日干固定展示为“日主”。
- 其他天干按日主计算十神。
- 地支主气和藏干也可以展示对应十神。

## 5. 藏干规则

藏干是地支内部包含的天干。

当前事实层输出每个藏干的：

- 藏干天干
- 藏干五行
- 藏干十神

常用藏干口径：

| 地支 | 藏干 |
| --- | --- |
| 子 | 癸 |
| 丑 | 己、癸、辛 |
| 寅 | 甲、丙、戊 |
| 卯 | 乙 |
| 辰 | 戊、乙、癸 |
| 巳 | 丙、戊、庚 |
| 午 | 丁、己 |
| 未 | 己、丁、乙 |
| 申 | 庚、壬、戊 |
| 酉 | 辛 |
| 戌 | 戊、辛、丁 |
| 亥 | 壬、甲 |

产品口径：

- 藏干属于事实层，不代表直接等比例计入五行分。
- 藏干怎么折算为五行能量，由五行评分算法决定。

## 6. 十二长生规则

十二长生状态：

```text
长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养
```

事实层区分两个字段：

| 字段 | 含义 |
| --- | --- |
| 星运 / lifecycle | 当前地支相对日主天干的十二长生 |
| 自坐 / selfSitting | 本柱天干坐本柱地支的十二长生 |

例子：

```text
庚金见子：庚在子为死
乙木坐亥：乙在亥为死
丙火见申：丙在申为病
```

边界：

- 十二长生是事实层字段。
- 当前五行能量算法没有把完整十二长生表作为主公式。
- “旺相休囚死”的月令状态和“十二长生的死”不是同一个概念。

## 7. 纳音、旬空规则

## 9. 神煞事实规则

神煞只表示“规则命中”，不单独生成吉凶结论。

当前事实层包含两类神煞：

1. 开源查表神煞。
2. 产品补充神煞。

### 9.1 查表神煞

查表基准：

| 分组 | 基准 | 匹配对象 |
| --- | --- | --- |
| 日干类 | 日主天干 | 四柱地支 |
| 年支类 | 年支 | 月、日、时地支 |
| 日支类 | 日支 | 年、月、时地支 |
| 月支类 | 月支 | 四柱天干或地支 |

当前包含：

- 天乙贵人
- 文昌贵人
- 阳刃
- 红艳
- 孤辰
- 寡宿
- 大耗

### 9.2 产品补充神煞

当前包含：

- 太极贵人
- 天厨贵人
- 国印贵人
- 金舆
- 红鸾
- 天喜
- 玉堂贵人
- 文星贵人
- 天印贵人
- 德秀贵人
- 学堂
- 正学堂
- 桃花
- 天罗
- 地网

关键口径：

- 天厨贵人：需要食神天干和食神禄位地支同时出现。
- 德秀贵人：需要对应月支规则里的德、秀天干同时出现。
- 学堂：依赖十二长生是否处于长生。
- 正学堂：学堂成立，且纳音五行与日主五行相应。
- 桃花：分别按年支、日支查。
- 天罗地网：会参考性别、年纳音和相关支位。

## 10. 天干关系事实

### 10.1 天干五合

| 组合 | 合化方向 |
| --- | --- |
| 甲己 | 土 |
| 乙庚 | 金 |
| 丙辛 | 水 |
| 丁壬 | 木 |
| 戊癸 | 火 |

事实层口径：

- 只要天干组合出现，就能命中五合事实。
- 是否真正“化成”目标五行，是更高阶判断。
- 五行评分层会另行判断能化、合而未化、扣原气等。

### 10.2 天干相克冲

当前显式识别：

```text
甲庚、甲戊、丙庚、丙壬、戊壬、
乙辛、乙己、丁癸、丁辛、己癸
```

产品口径：

- 事实层展示为天干相克冲。
- 不直接等同于事件凶断。
- 对五行能量的削弱由评分层决定。

## 12. 三合、半合、拱合

### 12.1 完整三合

| 组合 | 五行 | 中神 |
| --- | --- | --- |
| 申子辰 | 水 | 子 |
| 亥卯未 | 木 | 卯 |
| 寅午戌 | 火 | 午 |
| 巳酉丑 | 金 | 酉 |

完整三合要求三支都出现。

### 12.2 半合

半合要求中神出现。

规则：

```text
first + center = 半合
center + last = 半合
first + last = 不是半合，而是拱合
```

例子：

| 出现 | 事实 |
| --- | --- |
| 申 + 子 | 申子半合水 |
| 子 + 辰 | 子辰半合水 |
| 申 + 辰 | 申辰拱合子水 |

### 12.3 拱合

拱合是三合局两端出现，缺中神。

| 出现 | 缺 | 事实 |
| --- | --- | --- |
| 申 + 辰 | 子 | 申辰拱合子水 |
| 亥 + 未 | 卯 | 亥未拱合卯木 |
| 寅 + 戌 | 午 | 寅戌拱合午火 |
| 巳 + 丑 | 酉 | 巳丑拱合酉金 |

产品口径：

- 拱合属于事实层关系。
- 拱合强度低于完整三合和半合。
- 是否折算进五行能量，要由五行评分层决定。

| 巳午未 | 火 | 南方 |

## 14. 见干暗合局

当前事实层支持“见干暗合局”。

规则：

```text
三合局缺一个地支
缺支的藏干天干在可见天干中出现
则可命中见干暗合局
```

当前重点支持木局。

例子：

```text
亥未缺卯
卯藏乙
如果天干见乙
可命中：亥未见乙暗合木局
```

## 15. 关系强度

关系强度用于排序和展示轻重，不代表吉凶分。

当前大致排序：

| 关系 | 强度倾向 |
| --- | --- |
| 三合 | 很强 |
| 三会 | 很强 |
| 六冲 | 很强 |
| 三刑 | 较强 |
| 六合 | 较强 |
| 天干五合 | 较强 |
| 六害 / 六穿 | 中强 |
| 半合 | 中强 |
| 天干相克冲 | 中等 |
| 相破 | 中等 |
| 拱合 | 中等偏弱 |
| 拱会 | 中等偏弱 |
| 暗合 | 偏弱 |
| 暗会 | 偏弱 |

解释口径：

- 强度高 = 更值得解释。
- 强度高不等于一定好或一定坏。
- 吉凶需要结合日主、五行能量、原局结构和运势语境。

## 16. fact_panel 展示规则

`fact_panel` 是前端快速展示的压缩关系面板。

分组：

| 分组 | 含义 |
| --- | --- |
| heavenly_stem_natal | 原局天干关系 |
| earthly_branch_natal | 原局地支关系 |
| heavenly_stem_luck | 运势天干触发关系 |
| earthly_branch_luck | 运势地支触发关系 |

压缩规则：

- 同支 / 伏吟默认不进入面板。
- 完整三合成立时，相关半合、拱合、见干暗合局会被压制。
- 完整三会成立时，相关拱会会被压制。
- 暗合与见干暗合局重复时，会压制较弱展示项。

目的：

```text
保留最有解释价值的事实，避免一个命盘关系面板重复堆满。
```

## 17. 运势触发规则

原局关系：

```text
四柱之间互相比较
```

大运关系：

```text
大运 vs 原局
```

流年关系：

```text
流年 vs 原局
流年 vs 大运
流年 + 大运 + 原局形成混合关系
```

流月关系：

```text
流月 vs 原局
流月 vs 大运
流月 vs 流年
流月 + 上层时间因素形成混合关系
```

流日关系：

```text
流日 vs 原局
流日 vs 大运
流日 vs 流年
流日 vs 流月
流日 + 上层时间因素形成混合关系
```

产品口径：

- 运势层是“时间触发原局事实”。
- 同一个关系，在原局、大运、流年、流月、流日里的时间尺度不同。
- 大运偏长期，流年偏年度，流月偏月度，流日偏当天。

## 18. 前端和 AI 使用边界

前端：

- 命盘资料页直接展示排盘事实。
- 五行占比使用五行能量层，不从事实层推导。
- 关系面板使用 `fact_panel`。
- 关系详情使用完整 interactions。

AI：

- 必须以事实层为硬约束。
- 可以调整表达顺序和语言风格。
- 不能补写事实层未命中的关系。
- 不能把神煞命中直接写成绝对吉凶。
- 不能把关系强度当作吉凶分。
- 不能把事实层的拱合、暗合直接当成五行能量已加分。
