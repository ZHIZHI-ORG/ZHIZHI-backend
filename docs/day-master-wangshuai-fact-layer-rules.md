# 日主旺衰事实层规则文档

## 1. 产品结论

旺衰事实层回答的是：

```text
这个命盘里的日主，在原局里到底是强、弱、偏强、偏弱，还是接近中和？这个判断由哪些事实支持？
```

它对产品的意义：

- 用户看到的不再是泛泛的“五行很多 / 五行缺失”，而是能理解“我在这个命局里是否承载得住财官食伤”。
- AI 解读必须先引用旺衰事实，再进入性格、关系、事业和喜忌建议，减少没有证据的断语。
- 喜忌用神层可以使用旺衰结论做扶抑判断，但不能把旺衰结论直接等同于吉凶。
- 当前 `weighted_wuxing_v2_9` 已经有 `dayMasterStrength`，本文用于补齐它背后的命理事实解释和后续校准口径。

关键边界：

- 旺衰不是五行总量排序。金最旺不等于庚辛日主一定身旺。
- 旺衰不是喜忌。身弱不一定永远喜印比，寒热燥湿极端时调候优先。
- 旺衰不是吉凶。身强身弱本身只说明承载状态，吉凶要看结构、用神、运势触发。
- 旺衰事实层只判断原局基础状态；大运、流年、流月只做触发和阶段性修正，不能改写原局底盘。

## 2. 与现有规则文档的关系

| 文档 / 层 | 当前职责 | 本文如何使用 |
| --- | --- | --- |
| `mingli-fact-layer-rules.md` | 四柱、十神、藏干、神煞、干支关系事实 | 作为旺衰判断的事实输入 |

推荐层级：

```text
排盘事实层
-> 五行能量层
-> 旺衰事实层
-> 调候 / 扶抑 / 病药 / 通关判断层
-> 用户解释层
```

## 3. 主流理论框架

### 3.1 日主是判断中心

日主就是日柱天干，代表命局里的“我”。旺衰判断不是看全盘哪个五行最多，而是看“生扶日主的力量”和“克泄耗日主的力量”谁占优势。

白话解释：

```text
日主强弱 = 这个命盘里的“我”有没有根、有没有季节支持、有没有同党帮助，能不能承受外部压力和消耗。
```

### 3.2 月令是第一权重

主流子平体系重视月令。月令就是出生月份对应的地支，它代表命局的季节、环境、司令之气。

产品规则：

- 月令先决定五行季节状态。
- 月支藏干权重大于其他地支。
- 月令不能一票定旺衰，仍要看根气、透干、合冲制化。
- 月令结论要分成两个事实：季节旺衰和寒暖燥湿。

### 3.3 三得：得令、得地、得势

| 判断项 | 白话解释 | 事实来源 | 权重倾向 |
| --- | --- | --- | --- |
| 得令 | 日主或生扶日主的五行得到月令支持 | 月支、节令、季节状态 | 最高 |
| 得地 | 日主在地支有根，尤其月支、日支有根 | 地支藏干、通根、自坐 | 高 |
| 得势 | 天干地支里有印比党众帮扶 | 透干、藏干、十神、五行贡献项 | 中高 |

基础判断：

- 三者都得：身旺或极旺候选。
- 得令又得地：通常偏旺，除非被严重冲克泄耗。
- 失令但得地得势：可转为中和或偏旺，不能直接判弱。
- 失令、失地、失势：身弱或极弱候选。
- 只得其中一项：需要看该项强度，尤其月令和根气是否足够。

### 3.4 旺相休囚死

旺相休囚死是五行随四时变化的季节状态：

| 季节 / 月令 | 旺 | 相 | 休 | 囚 | 死 |
| --- | --- | --- | --- | --- | --- |
| 春：寅卯 | 木 | 火 | 水 | 金 | 土 |
| 夏：巳午 | 火 | 土 | 木 | 水 | 金 |
| 四季土：辰未戌丑 | 土 | 金 | 火 | 木 | 水 |
| 秋：申酉 | 金 | 水 | 土 | 火 | 木 |
| 冬：亥子 | 水 | 木 | 金 | 土 | 火 |

产品口径：

- `旺`：当令，季节直接支持。
- `相`：当令者所生，力量上升。
- `休`：生当令者，气退。
- `囚`：克当令者，被季节压制。
- `死`：被当令者所克，最弱。

重要边界：

- “旺相休囚死”是月令季节状态，不是十二长生里的“死”。
- 当前 `weighted_wuxing_v2_9` 使用的是平滑季节系数，不是完整显式的旺相休囚死标签。
- 本文建议新增标签层，但不要替换现有五行评分公式。

### 3.5 中和为贵

旺衰判断的目标不是寻找越强越好或越弱越坏，而是判断是否偏离中和。

产品口径：

```text
身旺 = 日主力量过盛，需要泄、耗、制来平衡。
身弱 = 日主承载不足，需要生、扶来补足。
中和 = 不强行扶抑，优先看调候、结构病点和通关。
```

## 4. 输入事实

旺衰事实层必须读取：

| 输入 | 用途 |
| --- | --- |
| 真太阳时后的四柱 | 保证年月日时事实正确 |
| 日主天干、日主五行 | 确定判断中心 |
| 月支 / 月令 | 判断得令、季节状态、寒暖燥湿 |
| 四柱天干 | 判断透干、得势、克泄耗 |
| 四柱地支 | 判断根气、地支党众、合冲刑害 |
| 藏干 | 判断本气根、中气根、余气根 |
| 十神 | 将五行关系转成印、比劫、食伤、财、官杀 |
| 干支关系事实 | 判断根气是否被冲破、合化是否改变气势 |
| 五行加权贡献项 | 提供当前数值底座和证据来源 |
| 十二长生 | 辅助判断状态，不作主公式 |
| 调候事实 | 标记寒热燥湿是否压过扶抑 |

## 5. 判断顺序

旺衰事实层按固定顺序执行：

```text
1. 校验排盘基础事实
2. 取日主与日主五行
3. 取月令，判断日主是否得令
4. 判断地支根气，输出得地程度
5. 判断天干透出和印比党众，输出得势程度
6. 统计生扶日主与克泄耗日主的力量
7. 检查合冲刑害、三合三会、合化是否改变根气或党势
8. 检查寒热燥湿是否需要调候优先
9. 检查从格、专旺、化格等特殊格局风险
10. 输出旺衰标签、证据链、置信度和限制条件
```

### 6.2 得令判定

以日主五行为中心：

| 日主季节状态 | 得令等级 | 解释 |
| --- | --- | --- |
| 旺 | full_command | 日主当令，月令直接支持 |
| 相 | partial_command | 月令生助日主，支持明显 |
| 休 | retiring_command | 日主生月令，气被泄，弱化但不等于无力 |
| 囚 | constrained_command | 日主克月令或被季节压住，支持不足 |
| 死 | dead_command | 日主受当令之气克制，失令明显 |

注意：

- 得令等级是事实，不直接等于最终标签。
- 月令中如果藏有日主同五行或印星，要同时进入得地判断。
- 辰戌丑未不能只写“土旺”，还要记录湿燥寒热差异。

## 7. 得地规则：根气

根气就是日主在地支里有没有同类或生扶来源。无根的日主容易虚浮，有根的日主更能承载克泄耗。

### 7.1 根气类型

| 根气类型 | 命中条件 | 强度 |
| --- | --- | --- |
| 同干根 | 地支藏干出现与日主完全相同的天干 | 最强 |
| 同气根 | 地支藏干出现与日主同五行的天干 | 强 |
| 印星根 | 地支藏干出现生扶日主的五行 | 中强 |
| 长生 / 禄 / 帝旺辅助 | 十二长生处于长生、临官、帝旺等状态 | 辅助 |
| 余气根 | 只在余气藏干出现 | 较弱 |

### 7.2 根气位置权重

| 位置 | 重要性 | 规则 |
| --- | --- | --- |
| 月支 | 最高 | 月令根气直接改变旺衰底色 |
| 日支 | 高 | 自坐根气贴身，影响承载能力 |
| 时支 | 中 | 输出、晚景、行动侧支撑 |
| 年支 | 中低 | 背景根气，距离较远 |

### 7.3 藏干深浅

| 藏干位置 | 强度 |
| --- | --- |
| 主气 | 强 |
| 中气 | 中 |
| 余气 | 弱 |

产品规则：

- 月支主气根可以显著上调旺衰。
- 日支主气根也要重视，尤其自坐禄旺。
- 年支余气根不能单独把身弱改成身旺。
- 根被冲、刑、合走时，要降级而不是删除。

## 8. 得势规则：党众与透干

得势看命局里有没有印比帮身。印是生我者，比劫是同我者。

### 8.1 支持日主的力量

| 力量 | 十神 | 作用 |
| --- | --- | --- |
| 生我 | 正印、偏印 | 给日主资源和来源 |
| 同我 | 比肩、劫财 | 给日主同党和承载力 |

### 8.2 消耗或压制日主的力量

| 力量 | 十神 | 作用 |
| --- | --- | --- |
| 我生 | 食神、伤官 | 泄日主 |
| 我克 | 正财、偏财 | 耗日主 |
| 克我 | 正官、七杀 | 克日主 |

产品规则：

- 天干透出的印比，比只藏在地支里更容易发挥。
- 月干、日支、时干贴近日主，影响大于年柱远端影响。
- 党众不只看个数，要看位置、月令、根气和是否被合冲。
- 当前 `dayMasterStrength` 把非印比力量统一放进 `drainScore`，后续可以拆成 `leakScore / wealthDrainScore / pressureScore`，解释会更准。

## 9. 合冲刑害与制化修正规则

旺衰不能在静态权重后停止。干支关系会改变力量是否稳定。

| 关系 | 对旺衰的影响 | 规则 |
| --- | --- | --- |
| 六冲 | 冲动地支根气 | 根气降级，月支 / 日支冲影响更大 |
| 六合 | 牵绊或合化 | 合而不化只轻微改变，能化才改变气势 |
| 三合 / 三会 | 聚集一方气势 | 成局时显著增强目标五行 |
| 半合 / 半会 | 局部聚气 | 只做中等修正 |
| 拱合 / 拱会 | 缺中神的潜在聚气 | 事实命中，旺衰修正较弱 |
| 刑害破 | 破坏稳定性 | 根气、党势降级，不直接定凶 |
| 天干五合 | 牵绊透干或合化 | 合化条件不足时不能把原五行完全改性 |
| 天干相克 | 贴身克制 | 月干克日干、时干克日干要重点记录 |

产品口径：

- 事实层先命中关系。
- 旺衰层判断这个关系是增强日主、削弱日主、增强克泄耗，还是只影响稳定性。
- 五行评分层是否加减 raw 分，由算法版本决定。

## 10. 调候优先规则

调候就是看命局是否太冷、太热、太干、太湿。

旺衰事实层必须输出调候提示，但不把调候直接并入旺衰标签。

| 调候状态 | 命中条件 | 对旺衰解释的影响 |
| --- | --- | --- |
| 寒重 | 亥子丑月、水寒湿重、火弱 | 即使日主有根，也可能发用不足 |
| 热重 | 巳午未月、火土燥热、水弱 | 身旺或财官旺时要看是否失润 |
| 燥重 | 巳午未申酉戌月，水弱，火土金燥 | 金木土的状态要结合润燥判断 |
| 湿重 | 辰丑亥子、水湿土重、火弱 | 土水结构可能泥滞，根气可用性下降 |

边界：

- 调候是气候问题，旺衰是日主承载问题。
- 调候严重时，喜忌层应先解决寒热燥湿，再看扶抑。
- 旺衰事实层只输出 `climate_status` 和证据，不直接给用神。

## 11. 特殊格局风险

v1 不直接终断从格、专旺格、化格，只输出风险标记。

| 风险 | 标记条件 | 产品处理 |
| --- | --- | --- |
| 从弱格风险 | 日主极弱，无根无印比，克泄耗一方成势 | 旺衰置信度降级，提示需格局层复核 |
| 从强 / 专旺风险 | 日主极旺，印比根气成片，无有效制化 | 不按普通身旺直接取克泄耗 |
| 化格风险 | 天干合化条件强，月令和地支支持化神 | 标记合化候选，不直接改写日主 |
| 假从风险 | 看似极弱但藏有根或运中扶起 | 降置信度，避免极端断语 |

## 12. 输出标签

当前建议沿用 `weighted_wuxing_v2_9` 的 `dayMasterStrength.score`，先补证据层。

| score | 英文字段 | 中文标签 | 产品解释 |
| ---: | --- | --- | --- |
| > 60 | `extremely_strong` | 极旺 | 日主生扶力量压倒克泄耗 |
| > 30 | `strong` | 身旺 | 日主有明显承载力 |
| >= -10 | `balanced` | 中和 | 扶抑不应强行定向 |
| >= -30 | `neutral_weak` | 稍弱 | 日主略弱，但仍有一定承载 |
| >= -60 | `weak` | 身弱 | 日主承载不足，生扶不够 |
| < -60 | `extremely_weak` | 极弱 | 日主严重无力，需检查从格风险 |

## 13. 校准现有 `weighted_wuxing_v2_9`

当前后端已经做对的部分：

- 天干、藏干、月令、通根、合冲刑害、三合三会、五行流通都进入贡献项。
- `dayMasterStrength` 计算时跳过 `day_stem`，避免把日主自己重复当作帮扶。
- 月令使用平滑季节系数，避免月令单独压倒全盘。
- 事实层已区分完整三合、半合、拱合、三会、拱会等关系。

需要补齐的部分：

- 显式输出 `得令 / 得地 / 得势`，让用户知道为什么强或弱。
- 显式输出 `旺相休囚死` 标签，但只作为季节事实，不替换 raw 分。
- 将当前 `drainScore` 拆成 `leakScore / wealthDrainScore / controlPressureScore`，区分泄、耗、克。
- 根气要输出“主气 / 中气 / 余气”和“根是否被冲合刑害影响”。
- 调候只输出事实标签，不能混进旺衰 score，否则会和喜忌层重复。

## 14. 最小落地路径

第一步：只做事实解释，不改现有分数。

```text
输入现有 weightedWuxing.contributions
-> 生成得令、得地、得势、调候、修正关系说明
-> 复用现有 score / label
```

价值：

- 前端可以立刻解释“为什么身弱 / 身旺”。
- 不影响当前五行百分比和已有测试。
- 后续算法校准有结构化证据，不再只调一个黑盒分数。

第二步：拆分 `drainScore`。

```text
supportScore = 印 + 比劫
leakScore = 食伤
wealthDrainScore = 财
controlPressureScore = 官杀
```

价值：

- 身弱财旺、身弱杀重、身弱食伤泄气能区分。
- 性格、事业、关系解读可以更具体。

第三步：特殊格局只做候选。

```text
special_pattern_flags = [follow_weak_candidate, dominant_element_candidate, transform_candidate]
confidence = low / medium
```

价值：

- 避免把极端盘按普通扶抑误判。
- 不在 v1 引入高争议格局终断。

## 15. 反例与防误判

### 15.1 不能只看五行数量

同样是金多：

- 庚辛日主生申酉月，有根有印比，可能身旺。
- 丙丁日主遇申酉金多，可能是财旺身弱。

结论：

```text
五行强弱是全盘能量，日主旺衰是以日主为中心的承载判断。
```

### 15.2 不能只看月令

日主失令但地支多根、天干印比透出，可能不弱。

日主得令但被贴身克泄耗、根气被冲，可能只是偏旺或中和。

### 15.3 十二长生不能直接替代旺衰

十二长生是辅助状态，不是完整旺衰公式。

例子：

```text
某日主在某支为“死”，不等于全盘身弱。
```

### 15.4 缺某五行不等于喜某五行

缺水不等于一定喜水。火弱寒重可能喜火，水再来反而加重寒湿。

### 15.5 身弱不等于一定差

身弱说明承载力不足，人生策略更依赖资源、团队、节奏和环境。吉凶要看用神是否可用、运势是否扶起。
